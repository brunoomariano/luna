# ADR-0009: Go as the implementation language

**Status:** Accepted
**Date:** 2026-08-06

## Context

Luna wants to be installable in one command and runs N leads in parallel, plus an
inactivity watchdog. The choice of language has to meet those two constraints at a phase
in which the design still changes.

## Decision

We adopt **Go**: a single binary, no runtime on the target machine; native concurrency for
the watchdog and for the N leads.

## Alternatives considered

- **Python** — faster iteration, but rejected because it requires a runtime and an
  environment per machine, in a project that wants to be installable in one command.
- **Rust** — stronger guarantees and aligned with the neighboring tools, but rejected for
  being too expensive for a phase in which the design still changes.

## Consequences

- **Positive:** one-command installation surface; concurrency without an external library.
- **Negative / costs:** we give up Python's faster iteration and Rust's stronger
  guarantees.
